# Atlas Note 利用ガイド

Atlas Noteは、Markdownを正本としてノートを管理するデスクトップアプリです。

## はじめに

- 左側でノートブックとノートを選びます。新しいノートは「新しいノート」から作成できます。
- 本文はMarkdownとして保存され、リッチテキスト表示とMarkdown表示を切り替えられます。
- 初回セットアップ時に、このガイドがノートとして1件作成されます。既存の保存場所を開いた場合や、ガイドを削除・編集した場合に自動生成し直すことはありません。

## 保存

自動保存は既定でONです。入力は短い待ち時間の後に保存されます。

自動保存をOFFにしても、入力内容は画面を閉じるまで下書きとして保持されます。Ctrl+S、アプリ終了、保存場所・保存空間の切替など、保存を伴う明示操作では下書きを保存します。保存に失敗した場合は、画面の「再試行」「破棄」を確認してください。下書きは永続的な復旧用バックアップではないため、重要な内容は通常の保存とバックアップを確認してください。

主なショートカットは次のとおりです。

- Ctrl+S: 現在のノートを保存
- Ctrl+N: 新しいノート
- Ctrl+F: 検索欄へ移動
- Ctrl+Z / Ctrl+Y: 元に戻す／やり直す

ショートカットは「設定 > ショートカット」で変更できます。文字入力やAI送信と競合するキーは割り当てできません。

## 編集と添付画像

リッチテキストのツールバーから見出し、リスト、コードブロック、水平線、表、Mermaid図を挿入できます。Mermaid図は表示中に拡大・縮小・リセットできます。表示倍率はMarkdown本文には保存されません。

Markdown表示では、見出し、箇条書き、番号付きリスト、コードフェンス、水平線、Mermaidフェンスを入力すると、対応する記法が補完されます。記法そのものを残したい場合はMarkdown表示で確認してください。

画像はノート本文へドラッグ＆ドロップすると、添付画像として保存され、その位置へ挿入されます。現在の添付画像はPNG/JPEG、1画像10MiB、1ノート合計64MiB、最大100画像までです。その他のファイル形式は添付対象ではありません。

## AIワークスペース

AIワークスペースは設定でON/OFFできます。会話は送信が完了した時点で同じ履歴へ自動保存され、履歴一覧からすべての保存済み会話を開けます。「新しいチャット」で別の会話を開始します。履歴の読み込みはAIへの再送信を行いません。

AI設定にはプロバイダー、モデル、認証情報が含まれます。APIキー、ノート本文、プロンプトを診断ログや問い合わせへ貼り付けないでください。Agentの本文変更は、設定された確認・競合チェックを経由します。

## 同期、バックアップ、保存場所

- 「保存場所」でノートとバックアップの保存先を確認・変更できます。
- WebDAV同期を使う場合は、同期先の権限、URL、TLS、プロキシを確認してください。
- バックアップの復元前には安全用バックアップが作成されます。復元先と内容を確認してから実行してください。
- 保存場所、保存空間、同期先の変更中は、未保存の変更を保存できない場合に操作を中止します。

## よくある問題

### 保存済みと表示されない

画面上部の保存状態を確認し、「再試行」を実行してください。競合の場合は最新版を再読込するか、下書きを競合コピーとして保存します。自動保存OFFではCtrl+Sを実行してください。

### ノートや添付画像が表示されない

設定の「保存場所」が意図したフォルダか確認し、アプリを再起動してください。復旧画面が表示された場合は、元の保存場所を変更・削除せず、診断情報と案内を確認してください。

### 同期できない

WebDAVのURL末尾、ユーザー権限、TLS証明書、プロキシ設定を確認してください。同期競合が表示された場合は、内容を確認してからローカル、リモート、両方のいずれかを選択します。

### 問い合わせに何を添付すればよいか

問い合わせ窓口は環境ごとに指定されます。指定された窓口がある場合は、設定の「ヘルプ」にある診断ログを必要な範囲だけ共有してください。APIキー、パスワード、本文、タイトル、プロンプト、ファイルパスは共有しないでください。

## 診断ログと問い合わせ

設定の「ヘルプ」から安全な診断ログを更新、コピー、ファイル保存できます。診断ログには操作の成否を調べるためのメタデータだけが含まれ、ノート本文、タイトル、APIキー、プロンプト、ツール履歴、ファイルパスは含まれません。

問い合わせ窓口は未設定・未公開です。窓口が案内されている環境では、その案内に従ってください。
