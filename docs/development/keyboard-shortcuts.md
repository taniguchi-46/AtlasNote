# キーボードショートカット

ステータス: アプリ内グローバルショートカット、設定画面のキーバインド変更、Markdown／Rich本文のUndo／Redoを実装済み（2026-08-28）。手動UI受け入れは未完了。

## 対象範囲

- Atlas Noteのアプリウィンドウがキー入力を受け取っている間だけ動作する。
- OS全体でAtlas Noteを呼び出すシステムホットキーは扱わない。
- 設定、インポート、ロック解除などのダイアログ、メニュー、キーバインド入力中はアプリ全体のショートカットを実行しない。
- IME変換中、AltGraph入力、キーリピートではアプリ全体の操作を重複実行しない。

## 操作と初期値

| 操作 | スコープ | 初期値 |
| --- | --- | --- |
| 元に戻す | ノート本文 | `Ctrl + Z` |
| やり直す | ノート本文 | `Ctrl + Y` |
| 新しいノート | アプリ全体 | `Ctrl + N` |
| 検索欄へ移動 | アプリ全体 | `Ctrl + F` |
| 設定を開く | アプリ全体 | `Ctrl + ,` |
| 同期 | アプリ全体 | 未割り当て |
| ノートをインポート | アプリ全体 | 未割り当て |
| 常に最前面を切り替える | アプリ全体 | 未割り当て |
| テーマを切り替える | アプリ全体 | 未割り当て |
| Markdown／Rich編集を切り替える | アプリ全体 | 未割り当て |
| AIワークスペースを切り替える | アプリ全体 | 未割り当て |

すべての操作は「設定 > ショートカット」で変更、解除、個別初期化、一括初期化できる。Undo／Redoも固定キーではなく、同じ設定値から解決する。

## キー設定の契約

- 判定はキーボード配列上の文字ではなく`KeyboardEvent.code`とCtrl／Alt／Shift／Metaの組み合わせを使う。
- Ctrl、Alt、Metaのいずれかを必須とする。F1〜F12は修飾キーなしでも割り当てできる。
- 同じ組み合わせを複数操作へ割り当てない。
- 選択、コピー、切り取り、貼り付け、太字、斜体、下線、AI送信など、既存の文字入力操作と衝突する主要キーは割り当てない。
- 入力中はEsc、Delete、Backspaceのいずれかで未割り当てにする。
- 保存形式はversion付きの`atlas-keybindings-v1`とし、不正値、未知version、重複は安全な初期値へ補正する。
- キー設定は端末ローカルの非秘密UI設定である。保存空間を切り替えても共通で、SQLite、Markdown、WebDAVへ保存・同期しない。

## Undo／Redoの契約

- 対象はノートタイトルではなく、現在開いているノート本文だけとする。
- Rich編集はTiptap StarterKitの固定キーマップを無効化し、ProseMirror historyを設定済みキーから明示実行する。
- Markdown編集は文字入力、削除、貼り付け、ツールバーによる整形をメモリ上の履歴へ記録する。連続入力は500ms以内を同じグループとして扱い、最大100段階を保持する。
- Undo／Redo後の本文は、通常編集と同じdirty draft、ノート単位保存lane、revision／CASを通してautosaveする。保存済みrevisionやWebDAV履歴を直接巻き戻さない。
- 新しい編集を行った場合はRedo分岐を破棄する。
- ノート切替、本文の外部再読込、競合下書きの破棄、編集モード切替、ロック、アンマウント時に履歴を破棄する。保護本文や別ノートの本文を履歴へ残さない。
- Agentが既存の保存契約で適用した本文変更は、通常のローカル編集履歴へ追加しない。変更前後はAIタイムラインで確認する。


手動確認では、初期値、変更、解除、重複エラー、再起動後の復元、Markdown／Rich双方のUndo／Redo、ノート切替後の履歴分離、ダイアログ・IME入力中の抑止を確認する。
